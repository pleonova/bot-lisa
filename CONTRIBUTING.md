## Getting started

- Open an issue or reach out before starting on a large feature, so we
  can make sure it fits the roadmap and no one duplicates work.
- Keep PRs focused — smaller, single-purpose changes are easier to
  review and merge.
- Follow the existing code style and patterns in the relevant part of
  the codebase (Android/Kotlin, Python eval pipeline, etc.).

## Questions
